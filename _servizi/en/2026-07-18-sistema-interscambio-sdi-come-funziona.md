<p>The e-invoice goes through the Exchange System, the SDI: an automatic checker that verifies the data and delivers the document to the recipient. Understanding the steps avoids rejections and delays.</p><h2>The invoice's journey</h2><p>You issue the XML file and send it to the SDI, which checks the data is correct and delivers it to the client using their recipient code or PEC.</p><h2>If the invoice is rejected</h2><p>You receive a notification with the reason, usually a wrong or missing detail. Fix it and resend within the deadline: a rejected invoice counts as not issued.</p><h2>Storage</h2><p>E-invoices must be stored by law. Dedicated tools do it automatically, but check that it is active.</p><div class="art-nota"><p>Always fill in the client's recipient code or PEC: it is the number one cause of failed deliveries.</p></div>
